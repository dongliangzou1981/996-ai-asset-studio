# Sprint 18 Productization

## 目标

Sprint 18 的重点不是增强 AI 能力，也不是增加模型，而是把工具从开发工具推进到可使用产品。

默认用户是小白，用户只负责验收。能自动完成的事情，不再要求用户手动配置终端、切换终端、检查端口、配置环境变量或查看日志。

## 已完成

- `/studio` 工作台用户可见文案中文化。
- 结果区升级为「结果中心」。
- 生成结果集中展示界面名称、生成时间、风格编号、预览图、资源入口、报告入口、验证状态。
- 增加页面内人工验收状态：
  - 待验收
  - 验收通过
  - 需要修改
- 增加页面内验收记录输入框。
- 新增中文入口脚本：
  - `启动工作台.ps1`
  - `环境检查.ps1`
- 保留底层自动化脚本：
  - `scripts/start_local_studio.ps1`
  - `scripts/check_studio_env.ps1`
- 优化生成失败提示，不再要求用户检查环境变量或查看日志。

## 用户启动方式

在项目根目录运行：

```powershell
.\启动工作台.ps1
```

脚本会自动检查环境、检查 Key、启动后端、启动前端，并打开：

```text
http://127.0.0.1:3001/studio
```

## 用户检查方式

如果生成失败，运行：

```powershell
.\环境检查.ps1
```

输出使用中文状态：

- 【正常】
- 【异常】
