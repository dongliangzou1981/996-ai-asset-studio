# 传奇手游主界面固定布局规范

Sprint 19 之后，主界面生成不再把布局交给 AI 自由发挥。AI 主要负责风格、色彩、纹饰、边框、图标样式、按钮材质和面板质感变化；核心操作布局必须稳定。

## 1. 左下摇杆区

左下区域固定为移动控制区域。

- 摇杆必须放在左下角或左下安全区。
- 摇杆周围不要放置高优先级系统入口。
- 摇杆区域不能被聊天、任务列表或装饰素材遮挡。

## 2. 右下技能操作区

右下区域固定为战斗操作区域，必须采用更符合手游操作习惯的扇形或环绕式布局。

必须包含：

- 主攻击键
- 技能键
- 锁定
- 切换目标
- 自动战斗或辅助操作

禁止：

- 把技能按钮做成竖排列表。
- 把主要技能按钮放到远离右手操作区的位置。
- 用装饰元素遮挡主攻击键或技能键。

## 3. 右上小地图区

右上区域固定为小地图区域。

必须包含：

- 小地图
- 地图按钮
- 全体/区域切换
- 坐标信息

小地图不能挤占右下技能操作区，也不能遮挡中央战斗展示区。

## 4. 顶部信息区

顶部区域用于展示运营和资源入口。

常见内容：

- 货币
- 元宝
- 充值
- 活动
- 首充
- 福利
- 开服入口

顶部入口可以根据版本风格调整数量，但整体应沿顶部横向排列。

## 5. 底部信息区

底部区域用于展示状态信息。

常见内容：

- 等级
- 经验
- 坐标
- 地图名
- 网络/状态
- 时间

底部信息不能影响左下摇杆和右下技能操作。

## 6. 右侧系统入口区

右侧系统入口区用于角色、背包、商城、活动、设置等系统图标入口。

- 位置相对固定，通常在右侧中上到中部。
- 图标数量可以变化。
- 不一定全部常驻，可以通过展开按钮弹出。
- 展开状态也不能遮挡右下技能操作区。

## 7. 聊天区

聊天区位于左下或底部区域，点击后弹出聊天面板。

聊天面板频道包括：

- 综合
- 掉落
- 系统
- 喊话
- 私聊
- 行会
- 组队
- 附近
- 世界
- 国家

常驻聊天展示应轻量，不能覆盖摇杆、技能键和中央角色展示。

## 8. 中央战斗展示区

中央区域用于展示角色、怪物、场景和战斗状态。

- 尽量保持干净。
- 不要被系统入口大面积遮挡。
- 装饰纹饰可以增强氛围，但不能改变核心操作区域位置。

## 9. 当前布局模板

工作台先提供以下模板选项：

- 经典传奇手游布局
- 1.76经典版
- 1.85合击版
- 沉默版本
- 热血版本

Sprint 19 阶段五个模板共用本规范。后续可以在不改变前端字段的前提下，为每个模板细化不同入口数量、图标密度和视觉权重。
