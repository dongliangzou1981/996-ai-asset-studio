# Rules

项目硬规则：

1. 生产优先，实用优先。
2. 所有功能必须服务于“产出可用素材”。
3. 不要优先做 Review / Report / Score / Dashboard / History。
4. 参考图默认参考布局，不默认参考风格。
5. 风格参考是可选参数：
   - 不参考
   - 30%
   - 60%
   - 90%
   - 高复刻
6. 生产层只关心 JPG / PNG。
7. PSD / PSB 是美术源文件，不进入生产流程。
8. JPG 用于：
   - 完整图
   - 背景
   - 大型面板
   - 预览图
9. PNG 用于：
   - 按钮
   - 图标
   - 技能图标
   - 装备格
   - 关闭按钮
   - 货币图标
   - 摇杆
   - 系统入口
10. A级组件必须透明 PNG。
11. 如果不能生成真实透明 PNG，必须显示 `transparent_warning`，不能伪装成功。
12. Codex 需要读取本地参考资料时，直接读取路径，不要求用户重新上传。
