# Project

项目名称：
996 UI Asset Studio

项目目标：
做一个可操作的软件，通过生产流程生成 996 引擎可用 UI 素材。

不是：

- AI研究项目
- 报告系统
- Dashboard系统
- Codex自动自测项目
- 只做主界面的小工具

核心目标：
用户可以在 Studio 中操作：

- 选择界面类型
- 上传参考图
- 输入需求
- 生成界面
- 查看预览
- 标记候选组件
- 人工确认
- 执行切图
- 查看 PNG/JPG
- 导出 996-ready

主界面 `main_ui` 是第一条验证生产线。

后续要支持：

- `bag_ui`
- `role_ui`
- `shop_ui`
- `activity_ui`
- `task_ui`
- `skill_ui`
