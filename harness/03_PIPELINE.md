# Pipeline

统一生产流程：

1. 选择界面类型
2. 上传参考图 JPG / PNG
3. 输入生成需求
4. 设置风格参考比例
5. 生成完整界面
6. 显示完整界面预览
7. 标记候选组件
8. 生成 candidate_preview 编号图
9. 显示候选组件列表
10. 人工勾选 confirmed
11. 执行切图
12. 输出 confirmed_components
13. Studio 中预览 PNG / JPG
14. 显示透明 warning
15. 导出 996-ready 包

主界面固定区域规范：

- 顶部信息区
- 右上地图区
- 右侧系统入口区
- 右下技能区
- 左下摇杆区
- 聊天区
- 底部状态区
