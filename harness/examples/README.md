- `main_ui/a0f65d04-bf20-4419-85df-e9a8e0d30898.png`

  - 可用于检查 Studio 双栏布局、结果中心宽度、响应式间距和首屏可操作性。

- `main_ui/0d7a616e-1b77-47da-b433-f50dc07da971.png`

  - 可用于后续验证 candidate_preview 编号框是否覆盖正确区域。
  - 当前样本重点是候选框边界与 Layout Zone 对齐，不是透明 PNG 问题。
